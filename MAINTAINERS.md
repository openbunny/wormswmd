# Maintainers

| GitHub | Role       |
| ------ | ---------- |
| `@OA`  | Maintainer |

## Succession

Unreachable means no commit, pull request review, or issue or pull request comment by the maintainer on github.com/openbunny/wormswmd for 90 consecutive days.

If the maintainer is unreachable, a contributor with a merged pull request may open a pull request naming a successor in this file and in `.github/CODEOWNERS`. It takes effect if no OpenBunny org owner objects within 14 days.
